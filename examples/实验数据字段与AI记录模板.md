# 实验数据字段与AI记录模板

实际数值由运行后的工程及原始数据填写，保留单位、复数定义和版本。未知值留空，不让AI补造。

## 每个工况的共同字段

case_id；实验编号；软件与版本；工程相对路径；参数；材料来源；求解器；端口/参考面；网格数；收敛指标；耗时；原始数据路径；运行日期；异常说明。

## 专项字段

| 实验 | 建议导出字段 | 关键定义 |
| --- | --- | --- |
| 超材料 | 频率GHz、各传播模式复数S、R/T/A、特征频率 | 模式、极化、功率波归一化、端口参考面 |
| 天线 | 频率GHz、S11实虚部、输入阻抗、带宽、D/G/实现G、效率 | 端口参考、θ/φ及极化、接受/辐射功率 |
| RF电路 | 全部复数S、K/μ、Pin/Pout基波、H3、HB阶数 | 参考阻抗、Touchstone顺序、峰值/RMS/复系数、可用功率 |
| 多物理场 | 吸收W、反射W、透射W、Tmax/Tmean K、散热W、时间s | 损耗来源、热域、法向、EM与热耦合方向 |

## 报告复现清单

- [ ] 保留基准工程及最终工程，参数与软件版本齐全。
- [ ] 原始数据与图对应；图有单位、频率和参考定义。
- [ ] 关键结论经过网格/频点/阶数/时间步核验。
- [ ] AI提出的改进已回代，未把预测当成求解结果。
- [ ] 记录失败、未达标及模型的适用范围。
- [ ] 引用官方资料和第三方材料；清理个人联系方式、凭据及学生隐私后再公开。
